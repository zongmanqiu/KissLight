## 使用说明

本项目使用了 `win-nightlight-lib` 库来控制 Windows 夜间模式。该库位于参考项目的 `win-nightlight-lib` 目录中。

在 `Cargo.toml` 中通过 git 引用：

```toml
win-nightlight-lib = { git = "https://github.com/kvnxiao/win-nightlight-cli.git" }
```
