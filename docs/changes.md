# KissLight 更新日志

## v1.0.0 (2026-08-23)

### 新增

- 系统托盘常驻，双击弹出调节面板
- 滑块实时调节色温（1200K - 6500K）
- 开机自动启用夜间模式
- 退出时恢复原始 Gamma 设置
- 单实例运行，避免重复启动
- 关于对话框：版本、作者、仓库链接、赞助二维码
- 无边框窗口，2px 黑色边框
- 窗口固定在屏幕右下角

### 技术

- 基于 Rust + 原生 Win32 API
- 使用 win-nightlight-lib 控制夜间模式
- 构建产物：KissLight_x64_1.0.0.exe（约 0.4MB）
